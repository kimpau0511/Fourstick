# FORSTICK Control Board

산업로봇 자연어 안전제어 흐름을 시연하기 위한 React 대시보드입니다. 모든 데이터와 상태 전환은 브라우저 로컬 상태로 동작하며 백엔드는 필요하지 않습니다.

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 우측 상단 `DEMO` 도구에서 사용자 역할과 상태 시나리오를 바꿀 수 있습니다.

## 확인 가능한 흐름

- 로봇 5단계 상태, 안전상태 3종, 연속값 임계 상태
- 질문, 차단, 검증 만료, 영상 끊김, 최종 승인, 실행, STOP·복구
- 알림 생명주기와 다중 긴급 집계
- 로봇 관리, 명령 기록, 시스템 진단, 권한별 설정 화면
