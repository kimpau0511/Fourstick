# 스펙 목록 (마스터 스펙)

기능마다 `specs/<기능-이름>.md` 하나(`_TEMPLATE.md` 복사). 진행 절차는 `docs/SDD.md`.

- 스펙 하나 = 한 세션에 들어가는 크기. 크면 쪼개고 아래 목록에서 서로 링크한다.
  거대한 단일 스펙은 세션 중간 압축에서 앞부분이 사라진다.
- 스펙 상태가 바뀌면 이 목록도 같이 고친다.
