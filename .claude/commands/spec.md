기능 설명: $ARGUMENTS

`docs/SDD.md`를 읽고 그 절차의 **1단계(설계)와 2단계(단계 분해)**를 수행한다. 코드는 쓰지 않는다.
결과는 `specs/_TEMPLATE.md` 형식의 `specs/<kebab-case-이름>.md`와 `specs/README.md` 목록 갱신이다.
준비 체크리스트를 스스로 대조해 빈 항목을 보고하고, 사람의 승인을 기다린다.

승인 전에는 스펙 파일과 목록 외의 코드·설정·docs를 바꾸지 않는다.

승인 뒤 구현(3단계)은 `docs/SDD.md` 구현 규칙대로 — 단계가 3개 이상이면 단계 하나씩 서브에이전트
(Agent 도구)에 맡긴다. 서브에이전트는 이 대화 기억 없이 시작하므로 "단계마다 새 세션" 규칙을 만족한다.
프롬프트에는 AGENTS.md·스펙 파일 경로와 단계 번호만 주고, 끝나면 상태 표를 확인한 뒤 다음으로 간다.
