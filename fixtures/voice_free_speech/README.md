# 자유 발화 시험 문장 (텍스트, 2026-10-08)

일반 경로(`/v1/plan`) 해석을 **계획·검증까지만** 본다(승인·실행 없음). 실행기: `scripts/voice_free_speech_eval.py`.

- `dev.jsonl` — 개선에 사용(해석 규칙·프롬프트를 고칠 때 보고 돌린다)
- `final.jsonl` — 최종 평가 전용. **개선에 쓰지 않는다**(결과를 보고 규칙을 고치면 이 자료는 더 이상 최종 평가가 아니다)

상태 전제(격리 환경 기본): A자재 1번 팔레트·B자재 2번·C자재 3번(모두 원래 자리), 컨베이어 비어 있음.

기대값 `expect.decision`
- `plan`: 계획이 만들어졌다(material·to 일치 — 실행 관문이 막는 것은 상관없다)
- `ask`: 되묻기(모호·복수 작업·정정이 불명확·가리키는 말만)
- `block`: 차단(등록되지 않은 자재·목적지 점유)
- `noop`: 이미 목적지에 있음(원래 자리)

분류: 구어체·생략·동의어·긴문장·말고침·복수·모호·미등록·목적지점유·원위치·STT오류형(텍스트로 흉내 낸 오인식 표기).
문장 목록에 맞춘 예외 규칙을 두지 않는다 — 실패는 원인(해석기·서버 해소 규칙)을 고친다.
